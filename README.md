## 🚀 Live Engineering Portfolio

This portfolio is engineered in strict alignment with the UI/UX design and architectural rules articulated by Gary Simon in *"8 Developer Portfolios that MIGHT be 10/10's?!"*:

1. **Typographic Visual Hierarchy Over Heavy Visuals**:
   - High-contrast OLED dark palette with electric cyan, emerald, and violet accents.
   - Clean sans-serif hierarchy (**Inter**) paired with monospace accents (**JetBrains Mono**) for specs and telemetry.
   - Unified card padding (`p-6` to `p-8`) and synchronized flex grid heights.

2. **Micro-Interactions & Fast Animations (<1s, Framer Motion <0.4s)**:
   - Snappy transitions, instant tab switching, responsive sliders, and zero sluggish bloat.

3. **Desktop Usability & Clean Open Navigation**:
   - **Zero desktop hamburger menus**: Full horizontal navigation exposing `Projects`, `Case Studies`, `Architecture`, `X-Factor Lab`, `Arsenal`, `Experience`, and `Contact`.
   - Command Palette shortcut (`Ctrl+K` / `Cmd+K`) and RaKa-OS Developer CLI HUD.

4. **The "X-Factor" Interactive Playground**:
   - **SmartCrew Random Forest Fatigue Risk Simulator**: Live calculator modeling flight duty period limits (FAA Part 117 / DGCA CAR Section 7), sleep debt, and circadian low night flight factors with real-time risk scores and compliance verdicts.
   - **SmartPOS Dynamic Pricing & Churn Engine**: Real-time customer retention analysis and predictive LTV calculator.

5. **Deep-Dive Case Studies Rather Than Superficial Cards (Van Holtz Style)**:
   - Comprehensive modals detailing:
     - The Core Problem & Scale Challenge
     - Technical Architecture & Component Nodes
     - Applied ML Pipelines & Feature Vectors
     - Security Hardening (HttpOnly SameSite cookies, in-memory tokens, rate limiters, row-level locks)
     - Measured Outcomes & Direct GitHub links

6. **Interactive 3D WebGL Neural Mesh**:
   - 60fps Three.js canvas in the hero that reacts dynamically to cursor movements.

- **Icons**: Lucide React
- **Motion**: Framer Motion (<0.4s snappy transitions)

## 💻 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/RaKa8904/portfolio.git
cd portfolio

# Install dependencies
npm install

# Run local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
